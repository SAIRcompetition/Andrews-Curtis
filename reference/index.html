Submission format

The benchmark defines one canonical encoding in AC-moves, so any path is checkable by anyone with no dependency on the solver that produced it.

The presentation

MS(n, w) starts as the two relators r0 = x⁻¹ yⁿ x y⁻⁽ⁿ⁺¹⁾ and r1 = x w⁻¹, freely reduced. Write w exactly as it appears in the data table, e.g. yxy^{-1}x^{-1}.

A path

A list of the AC-move ids 0–11 (below). Apply them in order, freely reducing after each. The path succeeds if the presentation becomes {x^{±1}, y^{±1}}. Path length is the number of moves.

Scoring

Solved is the primary metric (how many of 1190). Median path length is the tiebreak. A submission may cover any subset.
